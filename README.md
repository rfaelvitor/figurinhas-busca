# figurinhas-busca

Busca das figurinhas favoritas do WhatsApp por texto e por descrição.

- `app/`: app Android. Os resultados da busca vão para dois pacotes de figurinhas no WhatsApp ("🔍 Busca" e "🔍 Busca GIF").
- `tools/preparar_pacote.py`: converte as favoritas para o formato de pacote do WhatsApp e gera o `dados.zip` que o app importa.

As figurinhas e o índice não ficam no repositório.

Visão geral do projeto: [docs/fluxo.html](docs/fluxo.html)
